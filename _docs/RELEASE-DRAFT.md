# Черновик следующего релиза

Статус: подготовка; работы продолжаются. Номер версии, состав и дата выпуска не утверждены.

## Готовые изменения после v1.0.0

- Подключён премиум-сервер S5P: прямые AWG и Hysteria 2, отдельный каскадный вход с выходом через S5P. Выпуск ключей ограничен тарифом PRO.
- Дашборд показывает зарегистрированные узлы, отметки PRO и фактический выход каскада. Удалены устаревшие фиксированные подписи маршрутов.
- Телеметрия и перезапуск отдельного каскадного входа привязаны к его интерфейсу и менеджеру.
- Существующая конфигурация 3x-ui сохранена; основные маршруты кластера не переключались.

Проверены реальные подключения через премиум-каскад и Hysteria 2, запрет выпуска ключей для пользователей без PRO, отображение дашборда на компьютере и телефоне. Прошли `go vet`, тесты Go с race detector и сборка frontend. Подробности: `tasks/TASK-058-s5p-premium-dashboard.md`.
