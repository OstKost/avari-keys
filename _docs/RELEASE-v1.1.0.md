# Релиз v1.1.0

## Основные изменения

### 1. Сохранение роута и текущей вкладки (TASK-059)
- Интегрирован HTML5 History API (`pushState` / `popstate`) для полноценной навигации по разделам.
- При перезагрузке страницы (F5 / Cmd+R) и прямых переходах по каноническим ссылкам (`/news`, `/billing`, `/dashboard`, `/profile`, `/admin/users` и др.) активная вкладка сохраняется.
- Поддерживаются кнопки браузера «Назад» и «Вперёд».
- Добавлен автоматический fallback из `localStorage` (`avari_active_tab`) и поддержка хэшей (`#...`).
- Реализована защита доступа: при попытке пользователя без прав администратора открыть админский раздел система безопасно перенаправляет на `/keys`.
- Заголовок страницы (`document.title`) динамически обновляется при переходе между вкладками.

### 2. Новый чиби-маскот Ари (TASK-059)
- Персонаж-помощник Ари обновлён на милую чиби-версию.
- Выполнены удаление фона и сегментация с кристально чистым альфа-каналом.
- Подготовлены ассеты: полноростовая фигурка `mascot.png` / `mascot_transparent.png` (1024×1536) и центрированный аватар `mascot_avatar.png` (700×700).

### 3. Премиум-сервер S5P и дашборд (TASK-058)
- Подключён изолированный премиум-узел S5P: прямые подключения AWG и Hysteria 2, отдельный каскадный вход с выходом через S5P.
- Выпуск ключей ограничен тарифом PRO.
- Дашборд отображает актуальные зарегистрированные узлы, отметки PRO и фактический выход каскада.
- Телеметрия и перезапуск отдельного каскадного входа привязаны к его интерфейсу и менеджеру.

### 4. Новости и объявления
- Добавлено автоматическое заполнение таблицы `announcements` начальными объявлениями (`EnsureDefaultAnnouncements`) при первом запуске.
- Обновлены моковые данные новостей с актуальными сообщениями о каскаде, сбросе пароля и узле S4.

### 5. Версионирование
- Master Backend и Slave API возвращают версию `v1.1.0` на эндпоинтах `/health`.
- Фронтенд `package.json` обновлён до `1.1.0`.
