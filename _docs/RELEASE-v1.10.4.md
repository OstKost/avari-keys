# Релиз v1.10.4

## Критический фикс фильтра торрентов + per-node деплой в CI/CD

Релиз **v1.10.4** исправляет критический баг в `soft`-фильтре (блокировка loopback) и реструктурирует CI/CD-деплой нод.

---

### 1. Исправление блокировки loopback в торрент-фильтре (критично)

- **Проблема**: блок-лист доменов резолвился через DNS, и sinkholed-трекер отдавал `127.0.0.1`. Фильтр клал `127.0.0.1` в ipset и дропал loopback — из-за этого `health` эндпоинт таймаутился, ломалась аутентификация Hysteria2 (loopback-only), а ноды выглядели «мёртвыми» для панели.
- **Исправление**: `blockableIP` — из резолва выбрасываются loopback/private/link-local/multicast/unspecified адреса (`afd3120`). В ipset теперь попадают только публичные IP.
- **Сопутствующее**: доменная блокировка стала best-effort — при отсутствии `ipset` портовые правила применяются всегда (`1d1c0e1`); в `bootstrap_node.sh` добавлена установка `ipset`.

### 2. Per-node деплой slave-нод в CI/CD (неблокирующий)

- Монолитный цикл `deploy-slaves` заменён на `prepare-slaves` + `deploy-slave` **matrix** (`fail-fast: false`, отдельный шаг на каждую ноду).
- Ошибка деплоя одной ноды **не останавливает пайплайн** — остальные ноды продолжают деплой.
- При ошибке отправляется **уведомление в Telegram** (через опциональные секреты `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`); при отсутствии секретов — пропускается.
- Деплой устойчив к свежей/непровиженной ноде: egress-инсталл пропускается без `/root/awg`, а сервис стартует через `enable --now`, если ещё не активен (`9a0e37a`, `9b01fb2`).
