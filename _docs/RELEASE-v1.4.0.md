# Релиз v1.4.0

## Основные изменения

### 1. Комплексный редизайн списка серверов (нод) кластера (TASK-065)
- **Сводная панель метрик (Overview Ribbon)**:
  - В верхней части раздела размещены интерактивные карточки-счетчики: **Всего серверов**, **В сети (Online)**, **Сбои / Замечания**, **Каскады (M0 $\to$ Egress)**, **Прямые шлюзы** и **PRO Резерв**.
  - Клик по карточке метрики мгновенно фильтрует список (например, клик по «Сбои» показывает только проблемные серверы).
- **Панель быстрого поиска и фильтрации (Control Toolbar)**:
  - Полнотекстовый поиск в реальном времени по названию ноды, стране, 3-буквенному коду локации, IP/URL эндпоинта и названию хостинг-провайдера.
  - Быстрые фильтры состояния: *Все*, *Онлайн*, *Сбои*.
  - Кнопка **Health Check** с плавной анимацией процесса опроса серверов.
- **Два режима отображения (Сетка карточек $\leftrightarrow$ Компактная таблица)**:
  - **Сетка карточек (Grid View)**:
    - Фирменные Cyber-Fantasy карточки серверов с акцентной верхней полосой статуса.
    - Флаг и код локации, имя ноды (клик ведет на детальную страницу `/admin/nodes/:id`).
    - Пульсирующий маркер доступности и живой отклик API (`⚡ 24 ms`).
    - Блок маршрутизации: для каскадов отображается текущий активный шлюз выхода с кнопкой быстрого переключения в 1 клик.
    - Теги протоколов и опций: `AWG`, `Hysteria 2`, `443 LTE`, `PRO Резерв`.
    - Мини-панель здоровья: статусы сервера и сети, аккордеон с результатами сетевых зондов M0/S0.
    - Организованная панель действий: кнопка **«Диагностика»** и компактный тулбар сервисных действий (редактирование, перезапуск AWG, бэкап, восстановление, удаление).
  - **Компактная таблица (Table View)**:
    - Строго выровненное табличное представление с логичными заголовками (*Сервер*, *Маршрутизация*, *Протоколы*, *Здоровье & Пинг*, *Провайдер VPS*, *Действия*), устраняющее визуальную перегрузку.
    - Аккордеон сетевых зондов M0/S0 раскрывается плавно и не ломает соседние строки.
  - Режим отображения сохраняется в `localStorage` (`avari_nodes_view_mode`).
- **Модальное окно добавления сервера**:
  - Форма подключения нового Slave-сервера перенесена в модальное окно с затемнением и плавной анимацией через `createPortal`, не сдвигая контент страницы вниз.
- **Оптимизация блока Telegram-бота**:
  - Блок Telegram-оповещений стал компактным, поддерживает сворачивание, прямой переход в чат с ботом и отправку тестового алерта.

---

### 2. Конфигурация URL Telegram Mini App в настройках системы
- В раздел «Система» (`AdminSettings`) добавлено поле настройки внешнего URL Telegram Mini App, что позволяет администратору централизованно управлять адресом запуска TMA без ручного изменения конфигурационных файлов.
