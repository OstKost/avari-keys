# TASK-065: Комплексный редизайн списка серверов (нод) кластера

## 📋 Описание и цели
В текущей версии панель управления нодами (`AdminNodes.tsx`) отображала серверы исключительно в виде громоздкой HTML-таблицы. По мере расширения возможностей системы (зонды M0/S0, статусы здоровья сервера и сети, выбор шлюзов выхода каскада, протоколы Hysteria 2 / AWG, резервные ноды PRO, привязка VPS-провайдеров и 7 сервисных действий) таблица стала перегруженной, неудобной для восприятия и неадаптивной на мобильных и планшетных устройствах. Заголовок колонки «Название» отображал теги вместо имени, а детальные проверки растягивали строки таблицы.

Цели задачи:
1. **Сводная панель метрик (Overview Bar)** в верхней части страницы:
   - Общее число серверов, количество онлайн, количество с предупреждениями/оффлайн, соотношение каскадных и прямых нод, число PRO-нод.
   - Кликабельные фильтры быстрого отбора проблемных или каскадных серверов.
2. **Панель фильтрации и поиска (Control Toolbar)**:
   - Поле поиска в реальном времени (по названию сервера, стране, коду, IP/API URL и провайдеру).
   - Быстрые фильтры: Все, Онлайн, С замечаниями, Каскады, Прямые, PRO.
   - Переключатель режимов отображения: **Сетка карточек (Grid)** и **Компактная таблица (Table)** с сохранением выбора в `localStorage` (`avari_nodes_view_mode`).
   - Кнопка Health Check с анимацией и кнопка «+ Добавить Сервер» с фирменным золотым градиентом.
3. **Режим сетки карточек (Grid View)**:
   - Современные Cyber-Fantasy карточки нод с четкой иерархией.
   - Флаг и код локации, имя ноды (клик ведет на детальную страницу `/admin/nodes/:id`).
   - Индикаторы статуса (пульсирующий маркер доступности, API Latency в миллисекундах).
   - Блоки маршрутизации (Каскад с активным выходом Egress или Прямой туннель).
   - Теги протоколов (`AWG`, `Hysteria 2`, `443 LTE`, `PRO`).
   - Компактные бейджи здоровья (Сервер / Сеть / M0-S0 зонды).
   - Организованная панель действий: быстрая кнопка «Диагностика», переключение выхода каскада и аккуратное сервисное меню (Редактировать, Перезапуск, Бэкап, Восстановление, Удалить).
4. **Режим компактной таблицы (Table View)**:
   - Исправленное и строго выровненное табличное представление с корректными заголовками и смысловым разделением колонок.
   - Плавное раскрытие диагностических зондов без искажения соседних строк.
5. **Сохранение всех существующих сервисных функций**:
   - Переключение Egress каскада.
   - Создание и редактирование параметров ноды.
   - Резервное копирование и восстановление из `.bak`.
   - Перезапуск службы AWG на ноде.
   - Удаление ноды с подтверждением.
   - Управление оповещениями Telegram-бота.
