# TASK-071 — Двухрежимный интерфейс (Client / Admin Mission Control) и глубокий UX-апгрейд администрирования

## Цель и скоуп

Превратить панель управления Avari Keys из перегруженного набора таблиц в эргономичную систему с **четким разделением на два режима**:
1. **Клиентский режим (Client Mode)** — для повседневного использования личного VPN без лишнего визуального шума.
2. **Командный центр (Admin Mission Control)** — для дежурства, оперативного реагирования на блокировки ТСПУ, контроля каскада, модерации пользователей и мониторинга сетевой гигиены.

В рамках задачи реализуются:
- **Бесшовный Mode Switcher** в шапке с бейджами критических задач.
- **Экстренная панель быстрого реагирования (Egress Panic Bar & Quick-Switch)** с переключением Egress в 1 клик.
- **Сводный дашборд Mission Control (`AdminOverview`)** с визуализацией каскадной топологии трафика, блоком неотложных действий (Pending Action Center) и сводной аналитикой.
- **CRM-апгрейд раздела пользователей (`AdminUsers`)**: строка поиска, фильтр-вкладки (Ожидают / Сброс / PRO), пакетное одобрение в 1 клик, и **боковая шторка (User Detail Drawer)** со списком ключей и историей взносов пользователя.
- **Гигиена реестра ключей (`AdminAllKeys`)**: выявление «зомби-ключей» (неактивных >30 дней), фильтрация по Handshake и визуализация заполненности пулов IP-адресов.
- Полная синхронизация с `mockClient.ts` для автономного режима разработки (`npm run dev:mock`).

## Затронутые модули и файлы

- `apps/frontend/src/utils/route.ts` — добавление роута `'overview'`, логика разделения клиентских и админских роутов.
- `apps/frontend/src/App.tsx` — переключатель режимов (Client / Admin), реорганизация навигации, интеграция Panic Bar.
- `apps/frontend/src/components/AdminOverview.tsx` (новый) — главный экран командного центра с интерактивной топологией каскада, картами неотложных действий и метриками.
- `apps/frontend/src/components/AdminUsers.tsx` — поиск, фильтры, быстрые бейджи, пакетное одобрение и боковая шторка пользователя (User Detail Drawer).
- `apps/frontend/src/components/AdminAllKeys.tsx` — фильтры активности/зомби-ключей и индикатор пула IP подсетей.
- `apps/frontend/src/api/mockClient.ts` — поддержка согласованных данных и состояний для демо-режима.
- `_docs/TASKS.md` — обновление канбан-доски.

## Архитектурные инварианты и безопасность

1. **Zero CGo / Zero Breaking Changes**: Бэкенд и существующие API-контракты сохраняются на 100%. Все новые интерфейсные возможности опираются на существующие эндпоинты Master API.
2. **Изоляция ролей**: Обычные пользователи не имеют доступа к Admin Mode и админским роутам (автоматический редирект на `/keys`).
3. **Сохранение состояния (HTML5 History API)**: Режим и вкладки сохраняются в `localStorage` (`avari_app_mode`, `avari_active_tab`) и отражаются в адресной строке браузера (`/admin/overview`, `/admin/users`, `/keys` и т.д.).
4. **Синхронизация Mock Mode**: В демо-режиме (`dev:mock`) все новые UX-компоненты работают автономно.
