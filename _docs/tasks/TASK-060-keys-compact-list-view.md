# TASK-060: Минималистичный список конфигураций на странице «Мои устройства»

## 📋 Описание и цели
На странице **«Мои устройства»** (`activeTab === 'keys'`) конфигурации пользователя отображались исключительно в виде больших плиточных карточек. Когда у пользователя много устройств (телефоны, ПК, планшеты), карточки занимают много места.

Цели задачи:
1. Добавить переключатель режимов отображения: **Сетка (Grid)** и **Компактный список (List)**.
2. Сохранять выбор пользователя в `localStorage` (`avari_keys_view_mode`, по умолчанию `'grid'`).
3. Для компактного списка отображать в свернутом виде ключевые параметры:
   - Иконка типа устройства (смартфон/ноутбук) + название устройства + имя пира (`client_name`).
   - Маршрутизация (страна / каскад) + протокол (`AWG` / `Hysteria 2`).
   - Статус подключения (пульсирующий индикатор + `last_handshake`).
   - Трафик (суммарный и за месяц).
   - Быстрое действие открытия QR/конфига и поворотный шеврон.
4. Плавное раскрытие аккордеона на клик с полной информацией и действиями без скачков (CSS Grid `grid-template-rows: 0fr -> 1fr`).
5. Поддержка одновременного раскрытия нескольких строк.
