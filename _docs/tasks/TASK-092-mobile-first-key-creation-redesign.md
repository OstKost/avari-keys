# TASK-092 — Mobile-First Redesign мастера создания VPN-ключей

## Цели и скоуп

1. **Mobile-First UX создания ключа**:
   - Полная переработка модального окна создания ключей (`CreateKeyModal.tsx`) под мобильные экраны (320px–640px) и планшеты/десктоп.
   - Устранение наложения/скученности элементов в списке серверов: двухуровневая компоновка карточки сервера (Row 1: радио, флаг, имя и статус; Row 2: маршрут, теги и инфо).
   - Ликвидация лишней вложенности: ключевые параметры (протокол, сервер, имя) доступны сразу, без необходимости разворачивать спойлеры.

2. **Инверсия сценария: Протокол ДО выбора сервера**:
   - Выбор протокола (AmneziaWG, Hysteria 2, Mieru, VLESS+Reality) вынесен на первый шаг перед выбором сервера.
   - Список серверов динамически адаптируется под выбранный протокол:
     - Серверы, не поддерживающие выбранный протокол, помечаются неактивными (серый фон, `opacity-40`, `cursor-not-allowed`, отключенный radio-инпут) с понятным бейджем «Нет {Протокол}».
     - При переключении протокола, если текущий выбранный сервер не поддерживает новый протокол, интерфейс автоматически переключает выбор на первый валидный доступный сервер.
     - Заблокированные серверы (`is_blocked`) и серверы PRO для обычных пользователей сохраняют свои защитные блокировки.

3. **Опция Shadowrocket (PSK)**:
   - Анализ применимости: PresharedKey (PSK) применим **только к протоколу AmneziaWG** (Hysteria 2, Mieru и VLESS не используют WireGuard PSK). Для AmneziaWG опция применима **ко всем серверам**.
   - Показ переключателя Shadowrocket (PSK) строго при активном протоколе AmneziaWG; при выборе Hysteria 2, Mieru или VLESS блок скрывается, исключая дезинформацию пользователя.

4. **Согласованность с Telegram Mini App (TMA)**:
   - Синхронизация логики создания ключей в `TelegramMiniApp.tsx`: выбор протокола до выбора сервера, фильтрация/блокировка несовместимых серверов.

## Затронутые модули и файлы

- `apps/frontend/src/components/CreateKeyModal.tsx` — Mobile-First редизайн модального окна создания ключа.
- `apps/frontend/src/components/TelegramMiniApp.tsx` — согласование порядка и фильтрации серверов в TMA.
- `apps/frontend/src/api/mockClient.ts` — поддержка протоколов в mock-нодах для тестирования в `npm run dev:mock`.
- `_docs/TASKS.md` — статус задачи на канбан-доске.

## Контракты API и структуры данных (DTO)

Контракты backend API остаются неизменными:
`POST /api/v1/client/keys`
- `node_id`: number
- `device_name`: string
- `psk`: boolean (актуально только для `awg`, для остальных игнорируется/false)
- `protocol`: `'awg' | 'hysteria2' | 'mieru' | 'vless'`
