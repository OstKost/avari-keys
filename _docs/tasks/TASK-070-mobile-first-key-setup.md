# TASK-070 — Упрощенный сценарий создания профиля с телефона

## Цель и скоуп

Сократить путь пользователя от личного кабинета на смартфоне до рабочего VPN-подключения. Основной сценарий должен не требовать знаний о серверах, маршрутах, протоколах и PSK. По умолчанию используется рекомендуемый доступный узел и AmneziaWG; дополнительные параметры остаются доступными по явному запросу.

Обязательно провести пользователя по действиям на том же телефоне: создать отдельный профиль, скачать конфигурацию, передать ее в приложение AmneziaWG, включить подключение и увидеть статус Connected. QR-код остается полезен для переноса профиля на другое устройство.

## Затронутые модули и файлы

- `apps/frontend/src/components/CreateKeyModal.tsx` — мобильный путь создания, название устройства, скрытые расширенные настройки.
- `apps/frontend/src/components/KeyModal.tsx` — мобильная инструкция импорта и приоритет файла над QR.
- `apps/frontend/src/components/OnboardingTour.tsx` — согласованный пошаговый сценарий.
- `_docs/TASKS.md` — статус задачи.

API, DTO и серверная логика не меняются. Mock API сохраняет прежний контракт.

## Решение и интерфейс

### Создание

1. Заголовок объясняет результат: «Подключить устройство».
2. По User-Agent подставляется понятное имя `iPhone` или `Android`; на компьютере — «Моё устройство». Название можно изменить, вводить кириллицу разрешено.
3. На телефоне появляется короткое пояснение: создается отдельный профиль для текущего устройства, после создания нужно скачать файл и открыть его в AmneziaWG.
4. Пользователь сразу видит только название устройства и кнопку «Создать профиль».
5. Рекомендуемый узел и AmneziaWG выбираются автоматически. Сервер, протокол и PSK остаются в сворачиваемом блоке «Дополнительные настройки».

### Установка на том же телефоне

- iPhone/iPad: скачать `.conf`, открыть приложение «Файлы», нажать «Поделиться» и передать файл в AmneziaWG; затем включить профиль.
- Android: скачать `.conf`, в AmneziaWG нажать `+` → «Импорт из файла или архива», выбрать файл из «Загрузки» и включить профиль.
- QR-код объясняется как способ импорта на другое устройство, а не на экран, с которого пользователь его сканирует.

Инструкции сверяются с официальной документацией Amnezia: [Android](https://docs.amnezia.org/documentation/instructions/use-amneziawg-app/) и [iOS](https://docs.amnezia.org/documentation/instructions/connect-amnezia-premium/).

## Пользовательские сценарии

### Первый запуск на iPhone

Открыть личный кабинет на iPhone → нажать «Создать ключ» → увидеть предложенное имя `iPhone` → нажать «Создать профиль» → скачать `.conf` → открыть «Файлы» → передать конфигурацию в AmneziaWG → включить профиль → проверить статус подключения в приложении.

### Первый запуск на Android

Открыть кабинет → создать профиль с именем `Android` → скачать `.conf` → открыть AmneziaWG → `+` → импортировать файл из «Загрузки» → включить подключение → проверить статус Connected.

### Перенос на второе устройство

Создать отдельный профиль для второго устройства. Если второе устройство рядом, показать ему QR-код и импортировать его в приложении. Не переиспользовать файл первого устройства.

### Изменение параметров

Открыть «Дополнительные настройки» → выбрать другой доступный сервер/протокол или изменить PSK → создать профиль. Стандартный сценарий не раскрывает эти параметры без запроса пользователя.

## Чек-лист визуальной и функциональной проверки

- Проверить создание и экран импорта на ширине 320px и 390px, а также на 768px и desktop.
- На мобильном первом экране видны название и основная кнопка без обязательной прокрутки.
- Текст для iOS и Android соответствует действиям в официальной инструкции.
- Кириллица в названии не пропадает; длинное имя ограничено 64 символами.
- Расширенные настройки раскрываются и сохраняют работоспособность выбора сервера, протокола и PSK.
- QR-код и скачивание конфигурации остаются доступны для подходящего сценария.
- Проверить `git diff --check` и сборку frontend.
