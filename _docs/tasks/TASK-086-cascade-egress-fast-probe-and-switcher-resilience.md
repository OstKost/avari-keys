# TASK-086: Устранение таймаутов опроса Egress, исправление парсинга дампов AmneziaWG и отказоустойчивость переключения каскада

## 1. Контекст и проблема
При попытке открыть выбор выходов каскада в панели администратора (`AdminNodes.tsx`) или запустить ручную проверку шлюзов (`ServerDetailPage.tsx`) пользователь сталкивался с ошибкой:
> «Ошибка получения данных Egress / Failed to get egress status: context deadline exceeded»
и блокировкой кнопок переключения выходов («Не удалось получить статус Egress с узла»).

### Причины сбоя:
1. **Таймаут опроса шлюзов (16+ сек против 15 сек)**:
   При недоступности части резервных шлюзов (`awg2`, `awg3`, `awg4`) модуль `probe.go` последовательно опрашивал 4 провайдера внешнего IP (`api.ipify.org`, `icanhazip.com`, `ipinfo.io`, `api.myip.com`) с таймаутом по 4 секунды на каждый (суммарно 16+ сек).
   При этом `sharedHTTPClient` в `slave_client.go` на мастере имел жесткий лимит `Timeout: 15 * time.Second`. Мастер обрывал соединение до получения ответа от Slave и отдавал браузеру `HTTP 502: context deadline exceeded`.
2. **Критический баг парсинга дампа AmneziaWG в `CheckInterfaceDump`**:
   В стандартном WireGuard dump первая строка содержит 4 поля (параметры интерфейса), а строка пира — 8 полей.
   В AmneziaWG первая строка содержит свыше 20 полей (обфусцированные параметры `Jc, Jmin, Jmax, S1..S4, H1..H4`).
   Проверка `len(fields) >= 8` ошибочно принимала первую строку за пир: параметр `Jmin=47` парсился как `LatestHandshakeEpoch`, из-за чего возраст хэндшейка вычислялся как `now - 47 = ~56 лет` (29926570 минут), что ложно приводило к статусу `❄️ Завис` и рекомендации перезапуска даже для здоровых туннелей.
3. **UX в модалке `AdminNodes.tsx`**:
   - Отсутствовала возможность перезапустить зависший туннель прямо из модалки в 1 клик (вызов `api.restartNodeEgress`).
   - При сбое опроса отсутствовала кнопка повторной попытки («Повторить»).
   - Некорректно форматировался нулевой или аномальный возраст рукопожатия.

## 2. Скоуп изменений

### Бэкенд:
- **`internal/egress/manager.go`**:
  - В `CheckInterfaceDump` пропускать строку 0 (заголовок интерфейса), парсить пиры начиная со строки 1 (`idx > 0`).
  - При `LatestHandshakeEpoch == 0` не вычислять отрицательный или мусорный возраст рукопожатия, выставлять `0`.
- **`internal/egress/probe.go`**:
  - Добавить общий таймаут группы IP-проверок (5 секунд) и сократить таймаут одиночного HTTP-запроса провайдера до 2.5 секунд.
  - Быстрый выход при фатальных сетевых ошибках на мертвом интерфейсе.
- **`internal/client/slave_client.go`**:
  - Увеличить таймаут HTTP-клиента для взаимодействия Master ➔ Slave с 15 секунд до 35 секунд, гарантируя запас по времени для тяжелых сетевых проверок.
- **`internal/egress/egress_test.go`**:
  - Добавить unit-тесты для AmneziaWG дампа с 27 колонками в заголовке интерфейса.

### Фронтенд:
- **`apps/frontend/src/components/AdminNodes.tsx`**:
  - Добавить кнопку «Перезапуск» в строке каждого шлюза для быстрого сброса зависших туннелей прямо из модалки.
  - Добавить кнопку «Попробовать снова» при ошибке загрузки статуса Egress.
  - Корректная обработка отображения возраста хэндшейка.
