# TASK-075: VLESS+Reality

## Цель и скоуп

Добавить VLESS+Reality как четвёртый протокол на прямых нодах. Slave управляет выделенным Xray и отдельными UUID ключей. Каскады и поключевая телеметрия VLESS не входят в задачу.

## Модули

- Slave: конфигурация и управление Xray, безопасное хранение секретов, выдача и отзыв пользователей.
- Master и SQLite: доступность протокола, метаданные ключей, проверка прав и обработка ошибок отзыва.
- Frontend и Telegram Mini App: выбор протокола, управление нодами, отображение и экспорт ключей; синхронный mock API.
- Deploy и документация: настройка выделенной службы и восстановление конфигурации.

## Контракты

- `protocol: "vless"` в существующих API ключей.
- `has_vless` у ноды, `vless_available` в Slave health.
- Экспорт `vless://` и JSON-профиля, совместимого с AvariGate.
- UUID и приватный ключ REALITY хранятся только на Slave; Master сохраняет только метаданные.

## Проверка

- [x] Миграция существующей БД и совместимость со старыми Slave.
- [x] Независимый выпуск и отзыв UUID, перезапуск и восстановление после ошибки Xray.
- [x] Контракты API, права доступа, mock-клиент и UI.
- [x] `make test`, `make lint`, `make build-linux`, frontend build.
- [x] Проверка подключения и отзыва на тестовой прямой Linux-ноде.

## Результаты проверки

На Linux arm64 в Docker два ключа, выданные Slave, по отдельности передали HTTPS-трафик через Xray-core v26.11.9. После отзыва первый ключ получил отказ, второй снова подключился. В контейнере тестовый адаптер выполнял запуск и перезапуск настоящего Xray. Unit отдельно прошёл проверку systemd-analyze verify. Публичная нода в этом прогоне не использовалась.

Импортёр AvariGate Desktop прочитал URI и JSON одного ключа с одинаковыми параметрами. Chromium в режиме dev:mock проверил выдачу, отзыв, чтение второго ключа и появление QR. Go-тесты с race detector, go vet, сборки Master и Slave для Linux amd64/arm64 с CGO_ENABLED=0 и production-сборка фронтенда прошли. В package.json отдельный npm-скрипт lint отсутствует.

Инструкция для оператора находится в [VLESS.md](../VLESS.md).
