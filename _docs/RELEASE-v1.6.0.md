# Релиз v1.6.0

## Основные изменения

Релиз **v1.6.0** представляет масштабный продуктовый и визуальный апгрейд платформы **Avari Keys**, ориентированный на разделение контекстов использования («Клиент» vs «Командный центр»), повышение эргономики работы администратора при отражении блокировок ТСПУ и упрощение подключения мобильных устройств.

---

### 1. Двухрежимный интерфейс и Командный центр (Mission Control) (TASK-071)

- **Разделение на два режима (Clean Dual-Mode Switcher)**:
  - Вместо перегруженной двойной полосы из 11 вкладок интерфейс разделен на два изолированных контекста с переключателем в шапке:
    - **👤 Клиентский режим (`Клиент`)**: Фокус на повседневном использовании личного VPN без служебного шума (`Мои устройства`, `Статус сети`, `Новости`, `Биллинг`, `Мой профиль`).
    - **⚡ Командный центр (`Центр управления`)**: Рабочий стол администратора и дежурного инженера (`Сводка`, `Серверы`, `Пользователи`, `Все ключи`, `Логи`, `Настройки`, `Telegram App`).
  - **Индикатор внимания**: Кнопка переключения в шапке подсвечивает пульсирующей точкой наличие неотложных задач (ожидающие модерации пользователи, запросы сброса паролей).
  - **Синхронизация состояния**: Выбранный режим сохраняется в `localStorage` (`avari_app_mode`) и синхронизирован с HTML5 History API (`/admin/overview`, `/admin/users`, `/keys` и т.д.).

- **Экстренная панель реагирования (Egress Panic Bar & Quick-Switch)**:
  - Компонент [`EgressPanicBar.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/EgressPanicBar.tsx) закреплен в верхней части всех административных экранов.
  - Мгновенно отображает активный зарубежный шлюз каскада (`Каскадный Egress: S1 (Германия) 🟢`, кворум проверок `5/5`, статус серверов `online`).
  - Предоставляет кнопки экстренного перенаправления в 1 клик на резервные шлюзы (`S4 Нидерланды`, `S5P Финляндия PRO`) с подтверждением и toast-уведомлением.

- **Сводный дашборд Mission Control ([`AdminOverview.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/AdminOverview.tsx))**:
  - **Центр неотложных задач (Pending Action Center)**:
    - Интерактивные карточки: `Новые пользователи (N) ➔ Одобрить в 1 клик`, `Запросы сброса паролей (M)`, `Сбои серверов (K)`, `Задолженности по взносам (D)`.
    - При чистой очереди отображается статус «Все очереди пусты, система работает штатно».
  - **Интерактивная карта топологии каскада (Double-Hop Pipeline)**:
    - Графическая блок-схема движения трафика:
      `[Клиенты] ➔ [Входной шлюз M0 (Москва)] ➔ [WG туннель] ➔ [Egress S1 (Германия) ACTIVE] ➔ [Интернет]`.
    - Отдельный блок прямого сегмента (Direct-ноды: S2, SBOX с поддержкой Hysteria 2).
  - **Ключевые KPI кластера**: Сводка пользователей (Всего / PRO / Активные), реестр устройств (Конфигурации / Онлайн / Зомби), состояние нод и фонд взносов.

- **CRM-апгрейд раздела пользователей ([`AdminUsers.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/AdminUsers.tsx))**:
  - **Поиск и фильтрация**: Живой поиск по логину и ID, фильтр-пилюли (`Все`, `Ожидают (N)`, `Сброс пароля`, `PRO`, `Неактивные`).
  - **Массовые действия**: Кнопка `[✓ Одобрить все заявки (N)]` для пакетной активации новых регистраций.
  - **Боковая шторка профиля (User Detail Drawer)**:
    - Плавный выезд панели с подробной информацией о пользователе без перезагрузки страницы.
    - **Список устройств и конфигураций**: отображение имени устройства, протокола (AWG / Hysteria 2), привязанной ноды, времени последнего Handshake и кнопка точечного отзыва ключа.
    - **Быстрое управление учетной записью**: Активация/деактивация, переключение тарифа PRO, назначение/снятие прав администратора, удаление аккаунта.

- **Гигиена реестра ключей и мониторинг емкости подсетей ([`AdminAllKeys.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/AdminAllKeys.tsx))**:
  - **Фильтры жизненного цикла (Key Lifecycle)**:
    - `🟢 Онлайн (<15 мин)`
    - `Активны за 7 дней`
    - `💤 Спящие зомби (>30 дней без Handshake)` — быстрый способ выявить заброшенные устройства.
    - `Никогда не подключались`.
  - **Индикатор емкости подсетей (Subnet Pool Bar)**:
    - Прогресс-бар заполненности пула IP-адресов (`X / 253 IP, Y%`) с цветовой индикацией для предотвращения исчерпания диапазона `/24`.

### 2. Мобильный сценарий подключения устройств (TASK-070)

- **Мобильный онбординг первого ключа**:
  - Сокращен путь пользователя от личного кабинета на смартфоне до рабочего VPN-подключения.
  - Автоматическое определение User-Agent: понятные названия устройств по умолчанию (`iPhone`, `Android`, «Моё устройство») с поддержкой кириллицы.
  - Приоритет прямого скачивания файла конфигурации `.conf` над QR-кодом на мобильных экранах для импорта в приложение AmneziaWG в 1 тап.
  - Обновление обучающего сценария [`OnboardingTour.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/OnboardingTour.tsx).
