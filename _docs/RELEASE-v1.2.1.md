# Релиз v1.2.1

## Основные изменения

### 1. Отказоустойчивость и оптимизация автоматического деплоя Slave-нод в CI/CD (TASK-061)
- **Устранение конфликта мультиплексирования**: удален глобальный `ControlMaster auto` для `Host *` в пайплайне GitHub Actions. Ранее при использовании ProxyJump (`-J`) дочерний процесс проксирования (`ssh -W`) и основной процесс деплоя конкурировали за сокет мультиплексирования, что приводило к ошибкам `Connection timed out during banner exchange` и `Connection to UNKNOWN port 65535 timed out` на последующих узлах.
- **Увеличение таймаутов рукопожатия**: таймаут соединения `ConnectTimeout` увеличен с 15 до 30 секунд, включены `ServerAliveInterval 10`, `ServerAliveCountMax 3` и `TCPKeepAlive yes` для стабильного прохождения многокаскадных трансграничных маршрутов (GitHub Runner $\to$ Москва Jump Host $\to$ зарубежные VPN-ноды).
- **Исключение избыточного `ssh-keyscan`**: убран предварительный запуск `ssh-keyscan` перед каждым узлом. Ранее он выполнялся напрямую с IP-адреса GitHub Runner и генерировал пачки из 5 параллельных запросов на 22 порт, триггеря правила rate-limit фаервола UFW (`-m recent --hitcount 6 --seconds 30`). Благодаря опции `StrictHostKeyChecking accept-new` сохранение новых ключей серверов происходит чисто и безопасно при первом соединении.
- **Политика повторных попыток (Retry Policy)**: деплой каждого узла теперь защищен циклом из 3 попыток с паузой между попытками. Кратковременные сетевые задержки или дропы пакетов больше не ломают общий деплой кластера.
