# Релиз v1.2.0

## Основные изменения

### 1. Компактный режим списка ключей и устройств (TASK-060)
- **Переключатель отображения**: на странице «Мои устройства» добавлен тумблер переключения между карточной сеткой (Grid View) и компактным списком (Compact List View).
- **Сохранение предпочтений**: выбор режима автоматически сохраняется в `localStorage` (`avari_keys_view_mode`), по умолчанию для новых пользователей используется привычная сетка.
- **Минималистичная строка**: в свернутом виде отображаются иконка устройства (смартфон / ноутбук), имя устройства и пира, бейдж маршрутизации (`🇷🇺 RUS ➔ 🇳🇱 NLD`) и протокола (`AWG` / `Hysteria 2`), статус активности с пульсирующим индикатором и временем последнего рукопожатия, суммарный и месячный объём трафика, кнопка быстрого просмотра QR и поворотный шеврон.
- **Аппаратно-ускоренный аккордеон**: плавное раскрытие деталей ключа реализовано на современной технике CSS Grid (`grid-template-rows: 0fr -> 1fr`) и `opacity`, обеспечивая плавные 60 FPS на всех десктопных и мобильных браузерах.
- **Многострочное раскрытие**: возможность независимого открытия нескольких устройств одновременно для удобного сравнения телеметрии.
- **Архитектурный рефакторинг**: логика рендеринга вынесена в специализированный компонент [`ClientKeysView.tsx`](file:///Volumes/KingstonM2/Projects/avari-keys-mvp/apps/frontend/src/components/ClientKeysView.tsx), существенно облегчив `App.tsx`.

### 2. Мультиагентная архитектура и библиотека скиллов (AGENTS.md)
- **Библиотека локальных скиллов** в каталоге `.agents/skills/`:
  - [`antigravity`](file:///.agents/skills/antigravity/SKILL.md) — оркестрация, декомпозиция задач в `_docs/tasks/`, канбан-доска `_docs/TASKS.md`, Gitflow-контроль и релиз-менеджмент.
  - [`codex`](file:///.agents/skills/codex/SKILL.md) — fullstack-разработка Go (Zero-CGo, чистый SQLite, mock runner AWG) и React/Tailwind, синхронизация боевого `client.ts` и автономного `mockClient.ts`.
  - [`qa-tester`](file:///.agents/skills/qa-tester/SKILL.md) — регламент автоматизированного тестирования (`go test -race`, `go vet`, `make build-linux`, `npm run build`).
- **Универсальные наборы моделей**: определены четкие роли и матрицы вызова для Heavyweight/Reasoning (Pro, Sonnet, o1), Code Specialist (Codex, Sonnet) и Fast/Throughput (Flash, Mini) моделей.
- **Золотой стандарт (Golden Preset)** разработки: Pro (Архитектура) $\to$ Codex (Имплементация) $\to$ Fast (QA-верификация).
- **Стандартизация Handoff**: формализован протокол передачи задач между агентами без потери контекста.
