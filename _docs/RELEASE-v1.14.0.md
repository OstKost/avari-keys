# Релиз v1.14.0

## Reigns-style карточная колода ключей в Telegram Mini App (TMA), 3D-стек слоев и жестовые свайпы с Haptic-откликом

Релиз **v1.14.0** представляет интерактивное обновление вкладки ключей в Telegram Mini App ([TASK-093](./tasks/TASK-093-tma-reigns-swipe-keys.md)): отображение пользовательских VPN-ключей в виде физической 3D-колоды карточек в стиле игры **Reigns** / Tinder со свайпами, пропорциональным наклоном, игровыми штампами-подсказками и тактильным откликом.

---

### 1. Физическая 3D-колода карточек ([`TmaSwipeableKeyCards.tsx`](../apps/frontend/src/components/TmaSwipeableKeyCards.tsx))

- **Архитектура колоды**:
  - Карточки ключей выстраиваются в пространственный 3D-стек:
    - **Верхняя карта** (активный ключ): масштаб `scale(1.0)`, `z-index: 30`, интерактивная область с поддержкой горизонтальных жестов.
    - **Вторая карта** (следующий ключ): масштаб `scale(0.94)`, вертикальное смещение на 12px вниз, мягкое затемнение (`brightness: 0.75`, `opacity: 0.82`).
    - **Третья карта** (в глубине стека при наличии $\ge 3$ ключей): масштаб `scale(0.88)`, вертикальное смещение на 24px вниз, легкое контурное затемнение.
  - **Динамическое всплытие**: при перетаскивании верхней карты нижняя плавно масштабируется до `scale(1.0)`, поднимается и набирает яркость, создавая осязаемое физическое ощущение подъема новой карты из колоды.

---

### 2. Физика Reigns-свайпов и игровые штампы

- **Управление жестами (Pointer Events & Touch)**:
  - Поддержка как тач-скринов смартфонов, так и мыши/трекпада на десктопе через универсальный API Pointer Events с захватом курсора (`setPointerCapture`).
  - Сохранение естественного вертикального скролла страницы (`touch-action: pan-y`).
- **Характерный наклон Reigns**:
  - Карта вращается пропорционально смещению по оси X: `rotate(dragX * 0.07deg)` (наклон до 7–8° при оттягивании).
- **Игровые штампы-подсказки**:
  - При свайпе влево в правом верхнем углу карты проявляется неоновый бейдж **«Следующий →»** (`border-cyan-400`, `rotate-12`).
  - При свайпе вправо в левом верхнем углу проявляется бейдж **«← Предыдущий»** (`border-emerald-400`, `-rotate-12`).
- **Срабатывание и анимации**:
  - Порог фиксации: смещение $> 75\text{ px}$ или быстрый флик ($> 0.35\text{ px/ms}$). При превышении карта вылетает за экран с физическим затуханием, переключая колоду на следующий/предыдущий ключ.
  - Пружинный возврат (`cubic-bezier(0.175, 0.885, 0.32, 1.275)`): при незавершенном жесте карта упруго возвращается в центр.

---

### 3. Telegram WebApp Haptic & Instant Cache

- **Тактильная отдача**:
  - Легкий виброотклик (`triggerHaptic('light')`) при преодолении порога свайпа (с защитой от повторного дребезга через ref-триггер).
  - Подтверждение смены карты (`triggerNotificationHaptic('success')`) при завершении перелистывания.
- **Бесшовный in-memory кэш и предзагрузка**:
  - Локальный кэш конфигураций и QR-кодов (`Record<number, CachedKey>`).
  - Фоновая предзагрузка текущего и соседних ключей: перелистывание колоды происходит мгновенно, без задержек и повторных спиннеров загрузки QR.

---

### 4. Доступность и альтернативная навигация

- Навигационные стрелки («Назад» / «Вперед») для пользователей десктопа и любителей кликов.
- Индикатор пагинации и интерактивные точки («Ключ X из Y») с размером кликабельной области не менее 24px по стандарту WCAG 2.5.8.
- Быстрые чипы устройств вверху вкладки для мгновенного перехода к нужному ключу.
- Поддержка клавиш клавиатуры (стрелки влево/вправо).
- Поддержка `prefers-reduced-motion`: отключение резких вылетов для пользователей с чувствительностью к анимациям.
