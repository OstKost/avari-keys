# Релиз v1.11.0

## Детекция блокировок серверов по IP, статус «Заблокирован», 15-минутный Unblock Prober, авто-новости и ультра-лаконичные уведомления Telegram

Релиз **v1.11.0** решает ключевую эксплуатационную проблему доступности инфраструктуры при блокировках зарубежных серверов сетевыми провайдерами и ТСПУ из РФ ([TASK-089](./tasks/TASK-089-blocked-servers-detection-and-concise-alerts.md)). Заблокированные ноды больше не вызывают ложных срабатываний и зависаний цикла опроса, получают отдельный визуальный статус **«Заблокирован»**, периодически опрашиваются специализированным фоновым воркером с интервалом 15 минут, а все системные оповещения Telegram-бота переведены на ультра-лаконичный формат в 2–3 строки.

---

### 1. Детекция блокировок IP и выделенный статус «Заблокирован»

- **Проблема**: При блокировке прямого IP сервера сетевыми провайдерами РФ узел оставался полностью работоспособным в европейском контуре, но помечался как упавший (`Offline`), заставляя основной цикл опроса каждую минуту тратить время на таймауты.
- **Решение**:
  - В SQLite добавлена миграция `version: 5` (`node_blocked_state`), расширяющая таблицу `nodes` полями `is_blocked`, `blocked_reason`, `blocked_at`, `unblock_check_at`.
  - Узел получает отдельный визуальный статус строго **«Заблокирован»** (текст без перегрузки терминологией ТСПУ в лейбле).
  - При наведении на бейдж курсора тултип подробно объясняет ситуацию: *«Прямой доступ к IP заблокирован из РФ. Опрос снятия блокировки каждые 15 минут»*.
  - В интерфейсе администратора (`AdminNodes.tsx`) добавлен фильтр «Заблокированы», счетчик в панели метрик и визуальный багрово-янтарный акцент.

### 2. Fast-Path Bypass в HealthChecker

- Заблокированные серверы исключены из стандартного тяжелого цикла опроса работоспособности (`collectTelemetryAndHealth`).
- Для узлов со статусом `is_blocked = true` опрос пропускается мгновенно (0 таймаутов и задержек), что предотвращает зависание фонового воркера мониторинга.

### 3. Фоновый 15-минутный воркер `UnblockProber` и ручное управление

- В `monitor.HealthChecker` внедрен независимый легкий воркер `UnblockProber` с интервалом **15 минут**.
- Воркер выполняет направленный сетевой опрос заблокированных узлов из российского контура.
- **Авто-восстановление**: если сервер ответил успешно, статус блокировки автоматически снимается, сервер возвращается в рабочий пул, а в Telegram направляется алерт о доступности.
- **Ручное управление**:
  - На детальной странице сервера (`ServerDetailPage.tsx`) доступен блок управления: кнопка **«Проверить снятие»** (немедленная проверка через API) и кнопка **«Разблокировать»**.
  - Добавлена возможность вручную пометить любой узел как заблокированный.

### 4. Автоматическая публикация и снятие новостей-инцидентов без спама

- При переводе сервера в статус заблокированного система автоматически создает системную новость с тегом `[Инцидент]` и закрепляет её в баннере (`NewsBanner`) для информирования пользователей.
- Реализована дедупликация: повторные проверки не создают дублирующих новостей (`FindActiveIncidentNewsForNode`).
- При разблокировке сервера (автоматической или ручной) новость об инциденте автоматически удаляется (`RemoveIncidentNewsForNode`), очищая интерфейс без необходимости ручных действий администратора.

### 5. Защита мастера создания ключей (`CreateKeyModal`)

- В мастере создания ключей заблокированные серверы визуально приглушены и снабжены бейджем `🚫 Заблокирован`.
- Выбор таких серверов для обычных пользователей заблокирован с выводом предупреждения: *«Сервер заблокирован: прямой доступ из РФ ограничен. Создание ключей временно приостановлено»*.
- В `NetworkDashboard.tsx` статус отображается как информативный «Заблокирован» вместо тревожного «Недоступен».

### 6. Ультра-лаконичный рефакторинг уведомлений Telegram-бота

Все системные шаблоны сообщений бота переработаны. Полностью ликвидирована псевдографика (`━━━━━━━━━━━━`), шаблонные футеры и избыточные поля. Сообщения сокращены до **2–3 емких строк**:

- **Сбой сервера**:
  ```text
  🚨 Сервер недоступен: Прямой S1 - DEU (ID #4)
  ⚠️ Ошибка: context deadline exceeded
  ```
- **Восстановление сервера**:
  ```text
  ✅ Сервер восстановлен: Прямой S1 - DEU (ID #4)
  ⚡ Время отклика: 24 ms
  ```
- **Блокировка IP сервера**:
  ```text
  🚫 Сервер заблокирован: Прямой S2 - FIN (ID #3)
  ⚠️ Прямой доступ к IP ограничен из РФ (опрос снятия каждые 15 минут)
  ```
- **Снятие блокировки**:
  ```text
  🎉 Блокировка снята: Прямой S2 - FIN (ID #3)
  ⚡ Прямой доступ из РФ восстановился, сервер возвращен в работу
  ```
- **Новый пользователь**:
  ```text
  👤 Новый пользователь: @username (ID #12)
  📋 Требуется подтверждение аккаунта в панели управления
  ```
