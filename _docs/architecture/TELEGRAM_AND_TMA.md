# Telegram Bot и Telegram Mini App (TMA)

## 1. Архитектура Telegram-бота (`internal/telegram/`)

Telegram-бот выполняет роль оперативного канала мониторинга, модерации и взаимодействия с пользователями:
- **Режим работы**: Long-polling с автоперезапуском при сетевых сбоях.
- **Интеграция**: Запускается в фоновом режиме через `Server.StartBackgroundWorkers(ctx)` и останавливается через `Server.StopBackgroundWorkers()`.

### 1.1 Decoy-режим для неавторизованных пользователей
Если в бот пишет пользователь, не прошедший процедуру связывания учетной записи, бот отвечает нейтральной заглушкой (например, погода, время, эхо) и не раскрывает функционал VPN-платформы.

### 1.2 Связывание аккаунта по токену (Deep Link)
1. В веб-панели пользователь нажимает кнопку «Привязать Telegram».
2. Бэкенд генерирует криптографический токен (`telegram_link_tokens`) и формирует ссылку: `https://t.me/<bot_username>?start=link_<token>`.
3. При переходе бот получает команду `/start link_<token>`, находит пользователя в базе и сохраняет связку в `telegram_chats`.

### 1.3 Инлайн-модерация для администраторов
Администраторы получают интерактивные уведомления с inline-кнопками:
- **Новая регистрация**: Кнопка «✅ Одобрить» (`approve_user:<id>`) и «❌ Отклонить» (`reject_user:<id>`).
- **Запрос на сброс пароля**: Кнопка «✅ Подтвердить сброс» (`approve_reset:<id>`) и «❌ Отклонить» (`reject_reset:<id>`).
Все callback-запросы валидируются по доверенным `telegram_id` администраторов.

### 1.4 Системные алерты и рассылка новостей
- **HealthChecker**: При падении или восстановлении нод бот рассылает алерты администраторам (`NotifyOnNodeDown`, `NotifyOnNodeRecover`).
- **Новости**: При публикации новости с флагом `notify_telegram = true` бот выполняет фоновую рассылку подписчикам (`BroadcastNews`).

## 2. Telegram Mini App (TMA)

Telegram Mini App предоставляет полноценный доступ к платформе прямо из мессенджера Telegram:

### 2.1 Валидация сессии (HMAC-SHA256)
Аутентификация в TMA происходит без ввода пароля через криптографическую валидацию строки `initData`:
1. Из строки запроса формируется `data_check_string` (все параметры, кроме `hash`, отсортированные по алфавиту через `\n`).
2. Вычисляется секретный ключ: `secret_key = HMAC_SHA256("WebAppData", bot_token)`.
3. Вычисляется контрольный хэш: `calculated_hash = hex(HMAC_SHA256(data_check_string, secret_key))`.
4. Если вычисленный хэш совпадает с переданным `hash`, `telegram_id` считается достоверным, а бэкенд возвращает стандартный JWT-токен пользователя.
5. Защита от DoS: эндпоинт ограничен Rate Limiter на уровне **15 запросов в минуту**.

### 2.2 Двухрежимный интерфейс TMA (`TelegramMiniApp.tsx`)
- **Режим «Клиент»**:
  - Карточка пользователя и сводка потребления трафика за текущий месяц (TASK-082).
  - Список активных ключей с быстрым просмотром QR-кода и скачиванием `.conf`.
  - Модальное окно создания нового ключа с выбором страны/протокола.
  - Реквизиты и статус оплаты кооперативных взносов.
- **Режим «Администратор»**:
  - Сводка состояния кластера серверов (онлайн/ошибки).
  - Список нод с текущим статусом доступности.
  - Панель быстрого переключения Egress-шлюзов каскада (M0 Ingress $\rightarrow$ S1/S4) в 1 клик.
